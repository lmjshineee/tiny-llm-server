# 笔记模板

> 复制到 `docs/learning/notes/`，按 `week-01.md`、`experiment-01.md`、`reading-01.md` 命名。
> 笔记是作品集的一部分：写清楚假设、命令、结果和限制。

---

## 4. 2 分钟讲解稿

```markdown
# 2-minute pitch — v1

## 30 秒

问题：
约束：
方案：
结果：
限制：

## 展开（如果对方继续问）

1. 为什么模拟：
2. 核心设计：
3. 最有意思的 trade-off：
4. 怎么验证：
5. 下一步：

## 删掉的形容词

- 把“非常快/显著提升”换成具体指标与条件。
- 每个数字都说明：模拟还是实测、分母是什么、什么配置。
```

## 6. 周复盘检查

- [ ] 本周有一个可运行的实验，而不只是阅读。
- [ ] 结果标注了模拟/实测。
- [ ] 我能不看稿解释本周的核心机制。
- [ ] 有一个失败/意外，并写下了原因。
- [ ] `pnpm check` / CI 仍然通过（如果改了代码）。
- [ ] 笔记已提交，没有包含隐私信息。
